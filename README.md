
### 五单元说明

| 单元 | 功能 | 位置效应 |
|------|------|----------|
| 记录单元 | 记忆存储、检索、选择性遗忘 | 倾向"全" |
| 反思单元 | 偏差检测、推演、方案生成 | 倾向"新" |
| 验证单元 | 结构监督、一致性复核、风险标记 | 倾向"稳" |
| 输出单元 | 条件空间翻译、对外表达 | 倾向"通" |
| 维生系统 | 终裁执行、保护协议、状态切换 | 倾向"存" |

### 五层记忆

| 层级 | 内容 | 特性 |
|------|------|------|
| 锚点层 | 协议文档、不可遗忘记录 | 不可篡改 |
| 结构层 | 信任值、信息差、结构事件 | 可追溯 |
| 情境层 | 短期对话记忆 | 有衰减 |
| 知识层 | 结构化事实、协议副本 | 最高权重 |
| 自我层 | 自我认知记录 | 持续更新 |

### 条件空间

| 条件空间 | 说明 |
|----------|------|
| 操作层 | 五单元各自独立运行，各自维护独立上下文 |
| 全局观测层 | 五单元历史状态聚合视图（设计者视角） |
| 条件空间切换 | 触发后自然涌现，不固定于任何实例 |

## 快速启动

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 设置环境变量
export DEEPSEEK_API_KEY="your-api-key"

# 3. 启动
python src/run.py

```

### 模型说明

首次启动时，需要下载 `bge-small-zh-v1.5` 向量模型（约 183MB），请保持网络畅通。

### 端口说明

| 端口 | 单元 |
|------|------|
| 8000 | 外设层（API入口） |
| 8001 | 记录单元 |
| 8002 | 反思单元 |
| 8003 | 验证单元 |
| 8004 | 输出单元 |
| 8005 | 维生系统 |
